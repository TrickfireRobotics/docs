General knowledge and guidelines for writing C++ code for the club. These pages cover choosing types for your data, storing collections of values, and organizing a class into header and source files.

</Callout>

## What's covered

- **[Common Data Types](./data-types)** - primitives, strings, lists of values, queues, and stacks, including when to use each.
- **[Writing Classes](./classes)** - class members, constructors, header files, source files, and using a class in a program.
