<Callout type="error" title="Note on AI assisted coding">
    While we are a educational organization we are aware that in industry more and more code is being written with the assistance of AI then in the past few years. However, we recommend that you as an individual should try your best to learn the technologies, frameworks, and programming languages on your own before you start trying to contribute AI generated code.

    Trickfire as an organization cares more about you as an inidivudual learning, not as much the speed of the results, we understand that you may be new to this or learning something new. If you are contributing AI generated code, you should be able to explain what each part of the code you are contributing does as if you had written it yourself.

    Make sure that you still continue to follow software standards if you do end up generating AI code. In the case of writing AI generated code make sure to follow the REPO's `CLAUDE.md` or `AGENTS.md` if there is one, and most importantly **make sure the AI agent does not put itself as co-author**. Please put that in your global config or just tell the agent to never co-author things in Git or Github, they will get rejected.

</Callout>
